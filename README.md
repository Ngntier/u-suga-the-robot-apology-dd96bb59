A two-line robot confession: one sentence owning a specific, human-scale mistake (setting the thermostat to 30 instead of 20), and one naming the lesson and the changed behaviour that follows from it. This writes `entry.txt` (two lines, 212 characters) to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).

## Run it

```sh
python3 main.py
```
